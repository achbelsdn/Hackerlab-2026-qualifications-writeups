## About

Ce dépôt documente les résolutions réalisées pendant les qualifications du HackerLab Bénin 2026. Le catalogue et les métadonnées ont été relevés depuis la page authentifiée des challenges ; les solutions proviennent des notes du participant (`~/ctf/challenges/hackerlab2026/`, `~/ctf/knowledge/`, artefacts). Les missions marquées « notes non archivées » ont été résolues sur le portail mais leurs étapes détaillées restent à reconstituer.

Les catégories du portail incluent également **Network**, conservée ici comme catégorie distincte.
