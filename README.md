## About

Ce dépôt documentera les résolutions réalisées pendant les qualifications du HackerLab Bénin 2026. Les writeups seront ajoutés à partir des notes brutes fournies après la compétition ou après validation de leur publication.

Les catégories prévues sont : **OSINT**, **Web**, **Misc**, **Forensics**, **Boot2Root** et **Crypto**.

## Structure

Chaque challenge sera documenté dans son propre dossier, avec un `README.md`, un dossier `files/` pour les scripts, exploits et payloads, ainsi qu’un dossier `screenshots/` pour les captures pertinentes.
