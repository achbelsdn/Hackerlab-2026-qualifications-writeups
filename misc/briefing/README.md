# Briefing

**Catégorie** : MISC | **Points** : 60 | **Auteur du challenge** : Non renseigné | **Statut** : ✅ Résolu (6 × 10 pts)

## Description

Vous venez d'être affecté au CERT-TVS. Avant votre première opération, prenez connaissance du dossier de briefing. Chaque réponse se trouve dans la **page Univers** du portail (`ctf.hackerlab.bj/univers`).

## Recon / Enumeration

La page Univers est la « bible » du CTF : géopolitique fictive (Tervalis, Varélia, Norveth, Varelia…), organisations (FNS, TCDA, ASIN), nations et leur caractère (TLD bulletproof, agences de renseignement, APT attribués, cabinets offshore). Les six questions sont une lecture attentive du document.

## Questions

| # | Thème observé |
|---|---|
| Q1 | TLD de la nation spécialisée dans l'hébergement bulletproof |
| Q2 | Nom complet de l'agence de renseignement de Norveth |
| Q3 | Groupe APT attribué à Valdoria |
| Q4 | Officier de liaison entre le FNS et la TCDA |
| Q5 | Cabinet valdorien facilitant les structures offshore |
| Q6 | Élément caché dans le Discord du TCDA |

Chaque réponse est un extrait littéral de la page Univers (ou, pour Q6, un élément publié dans le Discord officiel du TCDA). Réponses trouvées par lecture ciblée du document, sans recherche externe.

## Lessons learned

- Les missions « briefing » valident la lecture du lore : la page Univers est une source primaire pour **toutes** les autres missions (noms d'organisations, personnages, attributions d'APT).
- Lire le lore en premier fait gagner du temps sur les OSINT et les scénarios de la suite.
- Les canaux officiels (Discord du TCDA) font partie du périmètre du challenge.
