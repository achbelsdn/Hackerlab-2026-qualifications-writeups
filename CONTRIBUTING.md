# Contribuer aux writeups HackerLab Bénin 2026

Merci d’aider à compléter les writeups des qualifications du HackerLab Bénin 2026.

## Comment contribuer

1. Ouvrez le dépôt et cliquez sur **Fork**.
2. Créez une branche dédiée, par exemple `writeup/nom-du-challenge`.
3. Complétez le `README.md` du challenge concerné en respectant le template existant.
4. Ajoutez les scripts, payloads et captures dans les dossiers `files/` et `screenshots/` correspondants.
5. Ne publiez jamais de secrets, tokens de session ou identifiants personnels.
6. N’ajoutez un flag valide que si sa publication est autorisée.
7. Ouvrez une **Pull Request** vers la branche `main` de ce dépôt.

## Format attendu

Chaque writeup doit conserver les sections suivantes :

- Description
- Recon / Enumeration
- Exploitation
- Flag
- Lessons learned (optionnel)

Merci d’indiquer le nom du challenge, la catégorie et les points lorsque ces informations sont connues.
