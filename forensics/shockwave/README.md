# Shockwave

**Catégorie** : FORENSICS | **Points** : 1550 | **Auteur du challenge** : [Sh1n](https://github.com/Sh1n)

## Description

Au cours d'un audit de routine des données télémétriques transmises via le réseau SCADA de TervaGrid, un analyste repère une séquence qui n'a rien à faire sur les ondes : quelque chose qui ne correspond pas aux relevés habituels. Vous incarnez le CERT de Tervalis. Partez de cette anomalie, déterminez ce qui se passe réellement sur le réseau et remontez la piste avant que Tervalis ne se retrouve dans le noir.
